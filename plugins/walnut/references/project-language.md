# Learn the project’s language

Use confirmed overview, decisions and authoritative docs to learn actors, terms, workflows and domain boundaries. No employer, product or industry is assumed.

Keep a small glossary in the shared record only when it resolves real ambiguity. Carry source, definition and confirmed renames; do not invent a vocabulary section to fill space. Existing domain terms remain valid in projects that use them.

Explain an unfamiliar term once in context. A renamed concept keeps its history and identity. If two sources use the same word differently, surface the ambiguity before conflating records. Examples and fixtures never establish the current project’s facts.
