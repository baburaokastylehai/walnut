# Fold: a first direction — 2026-10-18, 09:00 UTC

Fictional product-work dialogue. Fold and all observations in this walkthrough are invented.

**PM:** I'm playing with an idea called Fold for small design studios. They send work to a client, get comments, send another version… I wonder if collecting all that feedback in one place would help. We haven't spoken to studios yet, so this is a hunch.

**AI:** There are a few possible products inside that: a client workspace with projects and chat, an annotation editor, or a smaller review page. Which moment are you most interested in?

**PM:** The moment when the studio thinks something is approved and the client thinks they've just had a look. Let's start there. I don't want to build a whole workspace before we know whether that distinction is useful.

**AI:** One link per uploaded version would keep it clear what the client is reviewing. A comparison view could help them see what changed between versions.

**PM:** Let's use the separate version links as our starting direction. I'd also like to explore the comparison idea; my hunch is that it could make revisions easier to review. Don't put it in the pilot yet.

**AI:** Would clients need accounts? Or would access come from the link? We could also have AI approve a revision when it thinks all the feedback has been addressed.

**PM:** I'm not ready to settle access. I need to think about who can open these designs. Before we get further, I want to be precise about what “approved” means.

**PM:** When we share this with design, keep why we parked the workspace and why comparison is still just an idea. I want them to see the thinking behind the direction, not only the last sentence we agreed on. We don't need the whole brainstorm.
