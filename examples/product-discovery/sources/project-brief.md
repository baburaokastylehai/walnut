# Fold — initial project brief

Fictional. Approved by the PM in session 02, 2026-10-18 at 10:00 UTC. The later approved pilot scope update takes precedence where it changes this brief.

Fold is an early concept for small design studios reviewing work with clients. The PM is exploring whether clearer sign-off would help when feedback and approval get mixed together. No studios have been interviewed yet; this is a working problem hypothesis.

## Starting direction

Use a separate review link for each uploaded version. Defer the broader client workspace: onboarding clients into projects and chat would widen the pilot before the explicit-approval idea is tested. The concept is not built.

A client must explicitly approve the version they reviewed. Opening the design does not count as approval.

## Still being explored

The PM will settle how clients get access before pilot scope is ready. Accounts and link-based access are still competing approaches.

The PM wants to explore side-by-side comparison as a way to make revisions easier to review. It is an untested hypothesis, not committed pilot scope.

## What informed this

In a self-run scripted walkthrough, the PM used “approved” when the client had only opened the design. That observation motivated the explicit-confirmation requirement. It is not customer research and does not show how often the issue happens.
