Fold is an unbuilt pilot for small design studios to get explicit client sign-off on a deliverable. The problem is still a hypothesis, not a validated customer finding.

The current plan is one stable review page per deliverable, showing its current version. This replaced separate version-specific links after a scripted bookmark-return scenario exposed a harder path to explain. The first version focuses on approval; an annotation editor and a broader project workspace are deferred to keep the pilot narrow.

Clients will verify access with an email code, without creating accounts. Approval needs explicit confirmation, with the current version label visible, and must refer to that exact version. Viewing is not approval.

For engineering, that implies keeping approval identity distinct from page access and version identity. That's an implementation implication, not a specified schema. Code lifetime and technical choices remain unspecified. What happens to an earlier approval after a new upload is explicitly open for you and the PM to discuss; neither invalidation nor automatic carry-over has been decided.
